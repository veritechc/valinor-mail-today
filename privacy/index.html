VALINOR MAIL TODAY

Privacy Policy

Last updated November 7, 2026

Overview

Valinor Mail Today is a personal, self-hosted application used by its owner to view USPS Informed Delivery information. It is not a commercial service and is not offered to the general public.

Google user data accessed

The application requests the read-only Gmail scope. It searches a dedicated Gmail account for matching USPS Informed Delivery messages and reads only the information required to identify the delivery date, reported mailpiece and package counts, and valid mailpiece scan images.

The application cannot send email, modify messages, delete messages, change labels, or change Gmail account settings.

How Google user data is used

Google user data is used solely to provide the application's private USPS delivery-viewing functionality. Data is not used for advertising, profiling, credit decisions, or any unrelated purpose.

Storage and retention

Processed USPS delivery records and mailpiece images are stored locally on the owner's private server. Records and images are automatically deleted after 30 days. OAuth credentials are stored as protected local files and are not included in the public website or repository.

Sharing and disclosure

Google user data is not sold, rented, shared, or transferred to third parties. It is not transmitted to advertising platforms, data brokers, or analytics services.

Security

The private dashboard uses HTTPS, password authentication, restricted file permissions, least-privilege containers, and read-only Gmail access. No security method can guarantee absolute protection, but access is intentionally limited to the application owner.

User control

The owner can revoke the application's Google access at any time from the Google Account security settings. Local application data can also be deleted from the private server.

Google API Services User Data Policy

Valinor Mail Today's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be submitted through the GitHub repository issue tracker.
